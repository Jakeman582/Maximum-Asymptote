# Visualizations

Each visualization is created with a constructor, refined with fluent methods, and added to an `Image`. LaTeX math is supported in every label — use a **single** backslash in `.asy` strings (e.g. `"$\land$"`, not `"$\\land$"`).

Pick one from the sidebar, or jump straight in:

| Visualization | What it draws |
|---|---|
| [RelationDiagram]({% link visualizations/relation-diagram.md %}) | Functions, relations, and mappings between sets |
| [TruthTable]({% link visualizations/truth-table.md %}) | Truth tables for boolean expressions |
| [AccumulationTable]({% link visualizations/accumulation-table.md %}) | An iterative accumulation, one row per step |
| [Plot]({% link visualizations/plot.md %}) | Continuous explicit and implicit function graphs |
| [DiscretePlot]({% link visualizations/discrete-plot.md %}) | Discrete step/bar plots |
| [SwitchingNetwork]({% link visualizations/switching-network.md %}) | A boolean expression as a relay/switching network |
| [GraphDiagram]({% link visualizations/graph-diagram.md %}) | Graph-theory diagrams — vertices and edges, auto-placed |
